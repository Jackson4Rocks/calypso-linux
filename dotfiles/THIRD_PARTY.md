# Third-party integration

Calypso's Hyprland profile uses **Noctalia v5** as an external desktop shell dependency.

Noctalia is an independent open-source project licensed under the **MIT License**. Calypso's repository contains configuration and theming for Noctalia; it does not copy Noctalia's source code into this repository.

Upstream project: https://github.com/noctalia-dev/noctalia
Documentation: https://docs.noctalia.dev/
